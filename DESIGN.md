## Brand & Style

This design system embodies modern financial clarity, confidence, and understated luxury. Designed for premium wealth tracking, fintech dashboards, and business treasury platforms, the aesthetic prioritizes precision, legible information architecture, and tactile trust.

The design movement combines **Corporate Modernism** with subtle **Tonal Layering** and curated micro-depth:
- High contrast, dark charcoal typography against airy off-white backgrounds (#F8FAFC / #FFFFFF).
- Rich deep emerald forest greens (#006A4E) representing stability, growth, and security.
- Vibrant mint and soft green accents that communicate positive yields, liquidity, and active statuses.
- Clean compartmentalized card geometry with generous border radii (16px–24px), tactile pill tags, crisp neutral dividers, and delicate diffused ambient drop shadows.

## Colors

The color palette is anchored in forest emerald green paired with clean neutrals and crisp informational status colors.

### Palette Architecture
- **Primary (`#006A4E`)**: Deep emerald forest green used for primary action buttons, key highlighted hero cards (e.g., active wallet/balance), selected tabs, and brand signifiers.
- **Secondary (`#00875A`)**: Vibrant kelly/emerald green utilized for positive metric chips (`+1.5%`, `+3.2%`), active state badges, and primary bar chart highlights.
- **Tertiary (`#D1FAE5`)**: Soft mint green container tint for stat tags, active pill backgrounds, and soft gradient chart fills.
- **Neutral Dark (`#111827` / `#1F2937`)**: Deep charcoal black for display numerals, prominent titles, and active nav states.
- **Neutral Muted (`#6B7280` / `#9CA3AF`)**: Slate grey for secondary labels, breadcrumbs, timestamps, and column headers.
- **Neutral Border (`#E5E7EB` / `#F3F4F6`)**: Low-contrast hairpins defining table boundaries, card divisions, and subtle input outlines.
- **Backgrounds**:
  - App Canvas: `#F8FAFC`
  - Elevated Cards & Surfaces: `#FFFFFF`
  - Subtle Inset Wells: `#F3F4F6`
  - Dark Accent Surface: `#111827` (used for active sidebar menu pill and chart tooltips).

## Typography

The typographic system utilizes **Plus Jakarta Sans** uniformly across display, body, and numeric readout levels. Its geometric foundations, crisp tall x-height, and balanced apertures render financial numbers, micro-tables, and bold balances with maximum legibility.

### Hierarchy Guidelines
- **Financial Balance Readouts**: Rendered using negative letter spacing (`-0.02em`) with semi-bold to bold weights to maintain optical cohesion at scale.
- **Sidebar Category Headers**: Formatted in `label-sm` with uppercase transforms and open tracking (`0.04em`) to establish clear vertical segmentation.
- **Table Data & Metadata**: Kept strictly within `body-md` (14px) and `body-sm` (13px) for information density without sacrificing touch targets.

## Layout & Spacing

The layout is built upon an asymmetric desktop application shell:
- **Navigation Drawer**: Fixed 260px left sidebar featuring vertically stacked nav items, quick-access counters, search shortcut triggers (`⌘ K`), and contextual upgrade banner widgets at the bottom.
- **Top Bar**: 64px tall utility band containing navigation breadcrumbs, history controls, search/notification icon clusters, and user profile drawer.
- **Main Canvas**: Fluid 12-column responsive grid system with 20px–24px horizontal gutters.
  - KPI Top Section: 3-column card split (`col-span-4` each).
  - Analytical Mid Section: 5-column secondary wallet cluster (`col-span-5`) paired with a 7-column interactive cash flow visualization card (`col-span-7`).
  - Transaction Bottom Section: Full-width spanning (`col-span-12`) data table card with embedded header filtering.

### Breakpoints & Adaptive Reflow
- **Desktop (≥ 1280px)**: Persistent 260px sidebar, 3-column metric cards, split cash-flow and multi-currency modules.
- **Tablet (768px – 1279px)**: Collapsible icon rail navigation, 2-column stacked metric cards, stacked analytical cards.
- **Mobile (< 768px)**: Off-canvas hamburger drawer, single-column vertical flow, horizontal swipe containers for currency cards and tables.

## Elevation & Depth

This design system avoids heavy drop shadows, relying primarily on high-contrast surface layering, border demarcations, and soft ambient light casting:

### Surface Stack
1. **Level 0 (Base Floor)**: Canvas background `#F8FAFC`.
2. **Level 1 (Card & Module Foundation)**: Solid pure white `#FFFFFF` surface accompanied by a subtle 1px border (`#F1F5F9`) and ultra-soft diffused ambient shadow:
   `box-shadow: 0px 1px 3px rgba(17, 24, 39, 0.04), 0px 8px 16px -4px rgba(17, 24, 39, 0.02);`
3. **Level 2 (Hero Accent Card)**: Deep emerald gradient fill (`linear-gradient(135deg, #006A4E 0%, #004D38 100%)`) with soft inner glow and rich emerald shadow:
   `box-shadow: 0px 10px 24px -6px rgba(0, 106, 78, 0.24);`
4. **Level 3 (Floating Popovers & Tooltips)**: Pure dark slate tooltip `#111827` featuring crisp white typography, 12px border radius, and tight spatial elevation:
   `box-shadow: 0px 12px 28px -4px rgba(0, 0, 0, 0.28);`

## Shapes

The shape system leverages organic modern curvature designed to feel welcoming yet structured:
- **Card Containers**: `rounded-2xl` (16px to 20px) for elevated metric cards, analytics graphs, and table wrappers.
- **Interactive Badges & Nav Items**: `rounded-xl` (10px to 12px) for active sidebar links, table action buttons, and secondary input controls.
- **Tags, Metric Pills & Filters**: Fully rounded pill shapes (`rounded-full`, 9999px) for percentage changes (`+1.5%`), currency status badges (`Active`), and segmented control selectors (`Monthly / Yearly`).

## Components

### Buttons
- **Primary Action**: Deep emerald solid fill (`#006A4E`), white text, `rounded-xl`, 10px 18px padding. Hover: `#005740`.
- **Secondary / Ghost**: Pure white background, 1px border (`#E5E7EB`), `#111827` text, `rounded-xl`.
- **Segmented Toggle**: Pill container (`#F3F4F6`), with active option rendered in `#006A4E` with white text and passive option in `#6B7280`.

### Cards & Metrics
- **Hero Balance Card**: Rich emerald gradient with subtle organic glow, white numerical balance, top-right context overflow menu, and translucent bottom link row (`See details →`).
- **Standard Stat Card**: White surface, 1px `#F3F4F6` border, subtle icon badge on soft tinted grey background, large currency figure, positive green percentage badge (`#D1FAE5` background with `#00875A` text and upward arrow).

### Multi-Currency Wallet Items
- Compact card units with light borders, national flag avatars, currency code labels, large balance figures, monthly spending limit captions, and pill state badges (`Active` in soft mint, `Inactive` in soft orange/gray).

### Data Tables
- Flush, rounded-2xl white card housing.
- Header row with subtle `#F9FAFB` fill, uppercase muted label tracking, and built-in row selection checkboxes.
- Transaction items featuring icon indicators (software, travel, groceries), bold merchant titles, monospace invoice IDs, date/time timestamps, right-aligned monetary values, and dot-prefixed status badges (`• Completed` in green, `• Pending` in amber).

### Sidebar Navigation
- Active Item: Distinctive rounded dark slate pill (`#111827`) with white icon and typography.
- Inactive Item: `#6B7280` icon and text with soft `#F3F4F6` hover transition.
- Badge counters: Pill shaped, `#F3F4F6` background, `#374151` 11px font.
